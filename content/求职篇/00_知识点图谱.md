# 求职篇 · 知识点图谱

将《核心机制篇》12 章拆为可面试的知识点，标注依赖关系与面试频率，作为复习与出题的地图。

## 一、知识分层
- 基础层（打底）：推理-行动循环 ReAct、工具系统、上下文工程
- 中层（架构核心）：规划与分解、反思与自修正、多 Agent 协作、RAG 深度、能力扩展（MCP/FC/Skill）、编排与框架
- 上层（质量与落地）：评测与可观测、安全与合规、生产化 SRE

## 二、依赖关系（前置 → 进阶）
- ReAct → 规划 / 反思 / 多 Agent / 编排（都建立在"循环 + 工具"之上）
- 上下文工程 → RAG、生产化 SRE（记忆 / 缓存都是上下文管理）
- 工具系统 → 能力扩展（MCP/FC/Skill）、RAG（检索即工具）
- 规划与分解 → 多 Agent、编排
- RAG 深度 → 生产化 SRE（语义缓存）
- 评测与可观测 → 安全与合规 → 生产化 SRE（贯穿上线全链路）

## 四、30 天复习路线（建议）
- 第 1–5 天：ReAct、工具系统、上下文工程（打底）
- 第 6–10 天：规划与分解、反思与自修正、RAG 深度（核心）
- 第 11–15 天：多 Agent 协作、能力扩展、编排与框架（架构）
- 第 16–20 天：评测与可观测、安全与合规（质量与风险）
- 第 21–25 天：生产化 SRE（落地）
- 第 26–30 天：刷面试题库 + 模拟面试
