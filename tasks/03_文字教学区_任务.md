# 子任务清单 · 文字教学区_Theory/

> 模块定位：按知识点拆成的逐章讲义（K01–K11）。每章一篇，固定 7 节模板（见 `design_docs/02`）。
> 7 节：学习目标 → 核心概念 → 工作原理 → 主流方案 → 常见陷阱 → 自检题 → 动手引子。

## 每章通用工作项（对 K01–K11 各做一次）
- [ ] 写"学习目标"（可验证、可度量）
- [ ] 写"核心概念"（大白话定义 + 边界）
- [ ] 写"工作原理"（配图/伪代码主题）
- [ ] 写"主流方案"（对比 2–3 种实现）
- [ ] 写"常见陷阱"（学习者易错点）
- [ ] 出"自检题"（3–5 道，附答案要点）
- [ ] 写"动手引子"（指向对应 Lxx 小项目）
- [ ] 与对应 Lxx 对齐：前向钩子（讲→做）、反向钩子（做→回扣）
