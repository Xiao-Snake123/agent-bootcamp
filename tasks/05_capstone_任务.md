> 模块定位：学完 K1–K11 后做的综合性大项目，整合全部知识点。三主题三选一（详见规划书）。

## 启动
- [ ] 选定主题（A 深度研究助理 / B 自动化运营台 / C 代码工程 Agent）
- [ ] 在对应 `主题X_/` 建仓库，复用 `项目教学区_Labs/agent_core` 骨架（M0）

## 里程碑（以主题 A 为例，其余类比）
- [ ] M1 需求拆解：把大目标拆成可调度子任务，映射到 K/L 模块
- [ ] M2 集成骨架：把 L01–L11 的能力登记为可调用模块
- [ ] M3 接 RAG + MCP：引入私有知识检索与外部工具接入
- [ ] M4 多智能体协作：规划者/执行者/评审者角色就位
- [ ] M5 评估与安全：步数/成本预算 + 防注入 + 可观测落盘
- [ ] M6 演示与复盘：端到端跑通 ≥3 个真实任务并写复盘

## 验收三条件（必过）
- [ ] 端到端跑通 ≥3 个真实任务
- [ ] 每个模块可溯源到某个 K/L 知识点
- [ ] 含评估与安全设计（预算拦截 + 防注入）
